탐정학원 V3 · GATE 03

암호 풀이 화면. 2026-11-22 에 네 가지(예전 화면 / A안 접기·펼치기 / B안 장면 전개 / C안 혼합형)를 같은 문제로 나란히 놓고 B안으로 골랐다. C안(수사 수첩)은 다른 문제에 쓸 UI 후보로 남겼다.

예전 화면과 A안은 같은 날 보관하고 걷어냈다. 네 가지를 다시 나란히 보려면 docs/archive/v3-gate03-all-app/ 을 정적 서버로 열고 compare-play.html 을 본다(푸는 법은 docs/archive/README.md). 아래는 지금 남아 있는 두 화면이다. 둘 다 같은 문제(오늘의 추리 · 자료실 금고의 암호)를 실제로 풀고 제출할 수 있고, 판정·힌트·보상은 같은 엔진을 쓴다.

화면 크기

B안 · 장면 전개 (고른 안, 지금의 기본)

문제가 자료실의 장면으로 펼쳐진다. 들어서면 책상의 기록(시도 기록·메모)을 살피고, 금고 앞으로 가서 드럼을 돌린다. 장면의 책상·금고나 아래 단추로 언제든 오간다. 정답이면 금고가 열린다. 기록과 자물쇠를 한 화면에서 같이 볼 수는 없다.

B안을 전체 화면으로 열기

C안 · 혼합형 (수사 수첩) — 다른 문제용 후보, ?play=c

짧은 도입 장면 뒤 바로 자물쇠 앞이다. 조건은 수사 수첩에 담겨 있다: 표지를 누르면 접히고, 간편 보기는 기록의 숫자와 표시만, 전체 보기는 사건·기록·메모·받은 수사 지원을 다 보여 준다. 기록에 '중요' 표시를 하면 간편 보기에 그것부터 글과 함께 나온다.

C안을 전체 화면으로 열기

해 볼 것: ① 기록을 읽고 조건 이해하기 ② 숫자 메모로 5·7·9 지우기 ③ 드럼을 돌리다가 기록 다시 확인하기 ④ 일부러 틀려 보기 ⑤ 정답(직접 찾아보기) 제출. 볼 것: 이해하는 속도, 기록을 다시 보는 편의, 드럼을 돌리는 자리의 넓이, 화면을 오가는 횟수, 게임 같은 느낌. 자료실 장면만 따로 보려면 여기.
